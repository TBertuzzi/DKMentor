# Contributing

Bug reports and focused pull requests are welcome.

Please include the WoW Retail version, DK specialization, content type, steps to reproduce, whether the issue occurs in combat, and the complete Lua error when applicable.

Contributions must not include extracted Blizzard audio, copied third-party addon code, copied guide prose, or bundled third-party talent import strings. Keep combat behavior within Blizzard's addon/API restrictions.
