## DK Mentor 2.0.10 — Release Candidate

Final 2.0 release polish:

- Added **Test Alerts** for Defensive / Proc / Resource / Mind Freeze visuals.
- Added **Reset Mentor settings** while preserving the latest combat report.
- Added/confirmed **Reset HUD positions** recovery from Settings.
- Added `/dkm mentor test|reset`.
- Added a non-destructive migration guard for stale HUD anchors/coordinates from older installs.
- Added a one-time 2.0 upgrade notice explaining the Loadout Pilot split and recommendation-only behavior.
- Confirmed default Adaptive Coach mode remains **Mentor** with Combat Insights / compact post-combat popup enabled.
- Preserved the 2.0.9 Secret-safe Mind Freeze indicator and all Midnight 12.1 safeguards.

No loadout automation has been reintroduced. DK Mentor recommends actions but never casts abilities automatically.
