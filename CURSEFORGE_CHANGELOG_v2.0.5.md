## DK Mentor 2.0.5 — Adaptive DK Coach

- Upgraded the three-card Coach into a live **Adaptive DK Coach** with Essential, Mentor, and Training modes.
- Added a **Defensive Advisor** using readable health, recent damage, magic-pressure, Blood Bone Shield, and spec-aware recovery signals.
- Integrated interrupt handling into the Coach and added possible **Asphyxiate / Blinding Sleet / Death Grip** stops for non-interruptible non-boss casts.
- Added resource/proc coaching for near-cap Runic Power, idle Runes, Blood/Frost/Unholy proc windows including Frostbane, Frost Breath safeguards, and Unholy wound/disease state when readable.
- Added World/Delve elite survival emphasis and generic boss-cast DK response awareness without replacing DBM/BigWigs.
- Added **Combat Insights** and a **DK Mentor Score** after meaningful combats, with resource, proc, interrupt, and defensive-response analysis.
- Added a persistent last-combat panel to the Combat tab plus an optional click-through post-combat summary.
- Added **Mentor intelligence...** settings and `/dkm mentor essential|mentor|training`.
- Preserves all 2.0.1–2.0.4 UI, aura, click-through HUD, and Mind Freeze fixes.
- No ability automation and no loadout automation. SavedVariables schema remains 29.
