# DK Mentor 3.0.4 — Compact Live Mentor HUD

- Added Compact / Medium / Large Live Mentor layout presets.
- Compact is now the default layout for profiles without a saved Mentor layout preference.
- Reduced Mentor card size, icon size, padding, header footprint, and border emphasis without removing coaching information.
- Mentor width now adapts to one, two, or three populated cards.
- Moved health/state text to a dedicated small header line and shortened the movement hint to Move / Mover.
- Added Coach layout selection to Alert Studio while preserving Scale and Opacity fine tuning.
- Preserved all 3.0.3 Settings, preview-return, melee-warning, Review, Midnight, and crash fixes.
