# DK Mentor 3.1.0 — Preparation, Accessibility & Presets

- Added a visual **Preparation / Ready Check** to Gear Mentor with Runeforge, enchants, gems/sockets, flask, combat potion, healing potion, weapon consumable, augment rune, and food guidance for Blood/Frost/Unholy.
- Added Frost **2H vs Dual Wield** Runeforge awareness, including Shattering Blade handling.
- Added optional **Standard / SBA-friendly** Build Mentor views for players who use Blizzard's Single-Button Assistant. Guidance remains recommendation-only and clearly leaves defensives, interrupts, CC, utility, movement, and other situational decisions manual.
- Added **DK Mentor layout preset export/import** with a shareable `DKM31` text format. Imports are combat-blocked, bounded, data-only, and relock HUD movement after applying.
- Added an optional movable/scalable **Lich King commentary portrait** using WoW-native resources when available. No Blizzard art/model/audio files are bundled.
- Re-reviewed 12.1.0 Death Knight data on 2026-09-01 against current Blizzard hotfixes, Wowhead PvE/gear/consumable guidance, and Icy Veins PvP guidance.
- Refreshed Frost/Unholy PvP profile direction and current Season 2 preparation recommendations.
- Added `/dkm prep` and `/dkm preset`.
- Added English/ptBR text for all new 3.1 systems.

No automatic casting, target selection, talent switching, gear equipping, enhancement application, or consumable use was added.
