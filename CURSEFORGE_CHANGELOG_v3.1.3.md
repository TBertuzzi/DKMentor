DK Mentor 3.1.3 adds a selectable visual speaker for the animated commentary portrait.

## New
- Choose **Arthas** or **Bolvar** for the animated Lich King portrait.
- Portrait title/model update immediately when the selection changes.
- Added `/dkm voice portrait arthas|bolvar`.
- DK Mentor layout presets now preserve the portrait-character choice.
- Existing DKM31 presets remain compatible.

## Notes
- This changes the visual portrait only; the existing commentary voice resources are unchanged.
- No Blizzard model, texture, or audio assets are bundled.

## Version
- DK Mentor: **3.1.3**
- Retail interface: **120100**
