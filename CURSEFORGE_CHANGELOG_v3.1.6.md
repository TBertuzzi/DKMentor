# DK Mentor 3.1.6

## New
- Added **Preparation / Ready Check** for Runeforges, enchants, sockets/gems, consumables, and specialization-specific preparation.
- Added an optional **SBA-friendly** Build Mentor view for Blizzard Assisted Combat users.
- Added **DKM31 layout preset export/import** for supported HUD positions and visual settings.
- Added an optional movable/scalable **Lich King commentary portrait** with **Arthas or Bolvar** selection and animated playback.

## Improved and fixed
- Stabilized portrait position persistence across hide/show, playback, `/reload`, scale changes, character switching, and preset import/export.
- Fixed locked portraits incorrectly showing movement/preview helper text.
- Synced portrait animation/visibility to the real commentary sound handle when available.
- Corrected Bolvar to use his in-client Lich King model.
- Added a **Close / Fechar** footer action and fixed Layout Presets modal layering/dragging.
- **DK Ready / DK Pronto** now hides automatically during combat and returns afterward when enabled.
- Compacted the main DK Mentor window while preserving all existing controls.

## Season 2 guidance refresh
- Refreshed Blood, Frost, and Unholy **Gear Mentor / Preparation / DK Codex** guidance from current Patch 12.1 Season 2 sources.
- Updated Frost dual-wield gear/crafting/consumable/Runeforge direction, Unholy trinket target-count and AoE guidance, and Blood Runeforge/preparation direction.

## Build note
- PvE talent trees, Hero Talents, and PvP talent builds remain unchanged in 3.1.6 while awaiting verified post-September-1-hotfix guide updates. DK Mentor does not guess meta changes.

No Blizzard audio/model assets or third-party addon code are bundled.
