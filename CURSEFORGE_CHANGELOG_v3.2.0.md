# DK Mentor 3.2.0

## New — Stats & Folio Advisor
- Added a DK-only **Stats & Folio** Codex section for Blood, Frost, and Unholy.
- Shows live Crit/Haste/Mastery/Versatility percentages and ratings plus current diminishing-return thresholds.
- Adds specialization/Hero Talent stat direction with **Auto / PvE / PvP** planning modes.
- Added `/dkm advisor` for direct access.

## New — Omnium Folio Mentor
- Added five-row Folio recommendations for DK PvE/PvP.
- Safely compares recommendations with the live Omnium Folio selection when WoW exposes it.
- Read-only: DK Mentor never changes Folio runes.

## Gear Targets 2.0
- Added Blood/Frost/Unholy **Catalyst plans** from current Season 2 guidance.
- Added DK Mentor item-tooltip integration for tracked targets, crafts, and tier pieces.
- Tooltips show equipped/owned/missing state and which DK specs target the item.

## UI polish
- Added native WoW icons to DK Codex section navigation and key Build/Equipment/Advisor submenus.
- Icons are resolved from the WoW client only; DK Mentor bundles no new icon artwork.

## Data freshness
- Build, gear, and advisor guidance now expose **CURRENT / REVIEW PENDING** status and source dates.
- Frost/Unholy post-September-1 guidance has been re-reviewed and is CURRENT. Frost Mythic+ no longer recommends Frostbane; Unholy build direction remains stable.
- Frost Preparation now recommends Potion of Recklessness and uses the current dual-wield/two-hand Runeforge rules.

## Preserved
- Preparation / Ready Check, SBA-friendly guidance, DKM31 presets, Arthas/Bolvar commentary portrait, DK Pronto combat hiding, and Loadout Pilot handoff remain intact.

No third-party addon code/assets or Blizzard media are bundled.
