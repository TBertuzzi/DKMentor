# DK Mentor 1.0.13

This test build focuses on Frost proc visibility. Active DK procs are prioritized in the DK Buffs bar and, when Blizzard's tracked-buff Cooldown Viewer is available, DK Mentor mirrors its public active-state frames so the compact bar agrees with the buffs shown by the game UI.

No combat action is automated.


## Active-only DK Buffs

DK Buffs now displays only buffs/procs that are active right now. Blizzard Tracked Buffs/Tracked Bars are polled as the primary source, with proc glow and readable aura fallbacks.
