# DK Mentor 1.1.0

## Highlights

- New **DK Arcs** resource layout inspired by side-HUD readability.
- Shows **Health** on the left, **Runic Power** on the right, and **six Rune mini-bars** for recharge state.
- Keeps the original resource HUD as **Classic**.
- New DK Resources **Style** switch in **HUD appearance...**.
- New slash usage: `/dkm resources style classic` and `/dkm resources style arcs`.

## Notes

- The implementation is original to DK Mentor and does **not** copy IceHUD code.
- Position, scale, opacity, preview, and combat-only behavior stay configurable by the player.
- The existing **Restore DK Resources** action now also restores the default resource **Style**.
