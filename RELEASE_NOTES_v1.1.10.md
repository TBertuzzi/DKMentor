# DK Mentor 1.1.10

## Compact Build HUD

The Build HUD is now a single horizontal line: specialization icon, detected content, active talent build, associated equipment set, and DK READY status.

The specialization name and TALENTS AUTO / GEAR AUTO labels were removed from the HUD to reduce visual clutter. Auto-switch settings are still available in the Settings tab.

Manual specialization switching is fully preserved: click the specialization icon to open the Blood/Frost/Unholy selector.
