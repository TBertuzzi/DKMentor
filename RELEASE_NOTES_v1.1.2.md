# DK Mentor 1.1.2

## DK Arcs rebuilt

The DK Arcs style has been rebuilt to use the same kind of visual architecture that makes IceHUD easy to read: two vertical curved resource bars around the character.

- Left arc: **Health**
- Right arc: **Runic Power**
- Center: **six Death Knight Runes**
- Blood Runes: red accent
- Frost Runes: blue accent
- Unholy Runes: green accent

The implementation and textures are original to DK Mentor. IceHUD was used as an architectural/reference source only and is acknowledged in `THIRD_PARTY_NOTICES.md`.

The old **Classic** resources HUD remains available.
