# DK Mentor 2.0.1 - Release Notes

## UI polish

- The DK Codex **Builds** source row now gives the localized **Select source URL** button enough room, fixing the clipped PT-BR label.
- The URL field was shortened to preserve the existing row width and the **Open Loadout Pilot** button remains on the same line.
- The compact DK Status HUD is now substantially smaller: 32px tall with a 24px specialization icon.
- Context and **DK READY / DK PRONTO** sit closer together, and the widget no longer reserves a large empty area at the right.
- Width remains dynamic so longer localized content names can expand safely.

## Preserved behavior

- Left-clicking the specialization icon still opens the manual Blood/Frost/Unholy picker.
- Right-click still opens/closes DK Mentor.
- DK Ready still checks DK-specific readiness only.
- DK Mentor still performs no loadout automation; that responsibility remains with Loadout Pilot.
- SavedVariables schema remains 29.
