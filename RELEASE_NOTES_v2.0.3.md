# DK Mentor 2.0.3 - Release Notes

## Resource HUD no longer blocks target clicks

- Fixed the IceHUD-style Health / Runic Power arcs preventing clicks on enemies standing inside the transparent center area.
- The full arc HUD parent is now permanently click-through.
- When HUDs are unlocked and the player is out of combat, a small **Drag to move** handle appears above the arc area for repositioning.
- As soon as combat starts, the drag handle is disabled and hidden, even if the HUDs were left unlocked.
- Arc position saving, Health, Runic Power, six Runes, spacing, scale, opacity, and power text are unchanged.

## Preserved fixes

- 2.0.2 active-only DK Buff / External Buff / Debuff presentation.
- 2.0.1 compact status widget and PT-BR source URL button fix.
- No loadout automation inside DK Mentor.
- SavedVariables schema remains 29.
