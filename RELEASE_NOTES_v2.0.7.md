# DK Mentor 2.0.7 - HUD edit-mode polish

Version 2.0.7 makes the resource-arc drag handle strictly opt-in.

- HUD movement now starts locked on every UI session.
- The resource arc "Drag to move" handle appears only after HUDs are explicitly unlocked in the current session.
- Locking HUDs hides and disables the handle immediately.
- Combat or an unknown protected combat state also hides/disables the handle.
- The large arc parent remains permanently click-through so world units can be clicked between the arcs.
- All Adaptive DK Coach and Midnight safety fixes from 2.0.6 remain intact.
