# DK Mentor 3.0.14 — Gear Mentor crafting tab and Codex navigation refresh

DK Mentor 3.0.14 builds on the 3.0.13 readability hotfix with a usability pass focused on the **DK Codex** and **Gear Mentor**.

## What changed

### 1) New Crafting tab in Gear Mentor
A new **Crafting** tab was added to the Gear Mentor so players can quickly see which pieces are worth crafting when the recommended dungeon/raid drops still have not appeared.

### 2) Clearer Codex navigation
The old two-level top navigation inside the Codex could feel confusing because users first clicked a specialization and then needed to realize they also had to click the section buttons below.

To make this clearer, the section navigation is now presented as a **left-side menu inside the Codex panel**.

### 3) Better font readability
Additional contrast and text shadows were added to the lighter helper texts and content areas so the Codex/Gear Mentor remains easier to read.

## Summary
- New **Crafting** tab in Gear Mentor.
- **DK Codex** section navigation moved to a left-side menu.
- Improved readability for lighter/helper fonts.
- Keeps the updated Tier Set, Sources, Trinkets and Upgrades views from the previous gear work.
