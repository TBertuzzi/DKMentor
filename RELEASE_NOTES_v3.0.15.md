# DK Mentor 3.0.15 — Codex specialization buttons and section navigation polish

DK Mentor **3.0.15** refines the **DK Codex** interface with a small but important usability pass.

## What changed

### 1) Specialization icons on Codex buttons
The clickable specialization buttons in the **DK Codex** now show the proper **Blood / Frost / Unholy** icons.

### 2) Current button now reflects the active spec
The **Current** button now shows the icon for the specialization you are actively playing, making it easier to understand when you are following the live specialization instead of browsing another one.

### 3) Better section menu fit
The left-side **Sections** menu was adjusted so longer labels fit more cleanly and the Codex navigation looks more balanced.

## Summary
- Added specialization icons to Codex specialization buttons.
- **Current** button now uses the active specialization icon.
- Improved left-side section menu sizing and readability.
- No gameplay automation changes.

- DK Mentor: **3.0.15**
