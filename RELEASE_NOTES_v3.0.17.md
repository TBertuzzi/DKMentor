# DK Mentor 3.0.17 — Visual Build Mentor

DK Mentor **3.0.17** applies the same visual philosophy used by Gear Mentor to the **Builds** section of the DK Codex.

## What changed

### Visual Build Mentor
The Builds page is no longer primarily a wall of text. Each recommended profile is presented as a visual card with:
- Hero Talent icon and native WoW tooltip;
- recommended / alternative state;
- short focus description;
- important talent icons with native WoW spell tooltips;
- concise explanation;
- source, author, and guide-update date.

### Select the content you want to plan for
The Build Mentor now supports:
- Auto
- World
- Delves
- Dungeon
- Mythic+
- Raid
- PvP

**Auto** follows the content DK Mentor detects. Manual selection is for planning only and never changes your character.

### Current Patch 12.1 direction
Blood, Frost, and Unholy profiles were refreshed from the current reviewed guide direction for Patch 12.1. PvE profiles use current Wowhead class guides; PvP references continue to use current Icy Veins guidance where applicable.

### Localization
The new interface and recommendation explanations are localized for **English** and **ptBR**. Native spell names/tooltips come directly from the WoW client.

## Philosophy
DK Mentor recommends and explains. It does **not** import, select, or switch talent loadouts. Loadout automation remains the responsibility of Loadout Pilot.
