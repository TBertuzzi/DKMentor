# DK Mentor 3.3.1 - Release Notes

Release date: **2026-09-11**

This patch keeps the published 3.3.0 feature set intact and refreshes current Death Knight and Valeera guidance after a new source audit.

## Valeera: dedicated Nemesis / Azta'rec preset

- Added a dedicated **Nemesis / Azta'rec** preset instead of treating the Season 2 Nemesis fight as generic High Tier Delves.
- For Blood, Frost, and Unholy, Azta'rec now recommends **Healer Valeera + Corrosive Bilespear + Soul-Cracking Dreamcatcher + Phantasmal Spore Toxin**.
- **Soulthirst Venom** is documented as the guide-approved poison alternative.
- The existing High Tier preset is now described as **Hard Delves** only.

## Unholy Preparation refresh

Following the Wowhead consumables refresh reviewed on 2026-09-11, DK Mentor now also represents these current alternatives:

- **Powerful Eversong Diamond**
- **Flask of the Blood Knights** when Haste is valuable for the character's current stat balance
- **Refulgent Whetstone** for swords/axes
- **Refulgent Weightstone** for maces

Existing primary Unholy recommendations remain unchanged.

## Unholy PvP guidance correction

The current Icy Veins Unholy PvP page contains contradictory ranking text: its heading labels Disease as the best 3v3 build, while the detailed explanation says Disease is currently weaker than Pet. DK Mentor now reflects the more specific explanatory guidance:

- **Pet / Rider of the Apocalypse**: Recommended practical default
- **Disease / San'layn**: Alternative rot-pressure setup
- The source ambiguity is disclosed in the in-addon note instead of being presented as settled guidance.

## Blizzard hotfix review

- Reviewed the Blood **Grip of the Dead** permanent-effect bug fix.
- Reviewed the Unholy **Magus of the Dead** extreme vertical spawn-position fix.
- Neither change requires a DK Mentor combat-engine or talent-build rewrite.

## Full DK audit

Blood, Frost, and Unholy PvE builds, Hero Talents, gear targets, trinkets, crafting, tier-set guidance, stat priorities, and current PvP direction were rechecked. No broader build or gear rewrite was required.
