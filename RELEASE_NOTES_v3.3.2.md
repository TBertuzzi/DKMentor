# DK Mentor 3.3.2 - Release Notes

Release date: **2026-09-24**

3.3.2 is a focused post-tuning guidance update for the September 22 Death Knight pass and September 23 hotfixes. It does not change DK Mentor's combat engine or automation boundaries.

## Death Knight tuning refresh

- **Blood:** documents the September 22 Blood aura/Death Strike changes and the targeted Deathbringer buffs. The last Wowhead Blood talent guide is from September 21, so DK Mentor keeps the existing guide-backed profiles but marks their post-tuning ranking for review.
- **Frost:** records the PvE-only Frostreaper +100% and Obliterate +10% buffs. Existing Frostscythe 2+ and Glacial Advance 3+ guidance remains unchanged; the current talent page is still pre-tuning.
- **Unholy:** adds a visible **Single Target / San'layn Blightfall** raid alternative after Blizzard targeted Blightfall/San'layn on September 22 and fixed the Blightfall plague-age damage bug on September 23.
- **Unholy PvP:** keeps Pet/Rider as the provisional guide default but now calls out the September 22 San'layn PvP buffs and marks the old August Icy Veins ranking for review.

## Data freshness is now honest about the tuning window

Blood, Frost, and Unholy PvE build cards now show **REVIEW PENDING** when the last talent-guide revision predates the September 22 tuning. Unholy PvP does the same until Icy Veins publishes an updated comparison.

DK Mentor does **not** manufacture a post-tuning winner or replace talent imports without an updated guide-backed source.

## Gear, tier, crafting, stats and Preparation

Re-audited all three specs. No current source change requires replacing the existing gear targets, trinkets, crafting, tier-set guidance, Catalyst priorities, runeforges, consumables, or stat priorities. Review metadata is advanced to September 24 without unnecessary data churn.

## Valeera

- Added Blizzard's September 23 faction-change recovery hotfix to the live-hotfix panel.
- Existing Season 2 recommendations remain unchanged: Corrosive Bilespear + Soul-Cracking Dreamcatcher general baseline and the dedicated Azta'rec/Nemesis Healer preset for DKs.
