# DK Mentor 3.3.3 Test r1 - Release Notes

Review date: **2026-09-26**

3.3.3 consolidates the Unholy PvE meta after the September 22 Death Knight tuning and September 23 Blightfall hotfix. The current Wowhead recommendation body now favors San'layn for Single Target/Cleave and Mythic+/Delves, while Rider remains the Open World choice. DK Mentor now reflects that direction instead of keeping the provisional 3.3.2 ordering.

## Unholy PvE recommendation changes

- **Raid / Single Target:** San'layn + Blightfall is now **Recommended**. Rider moves to **Alternative**.
- **Mythic+:** San'layn + Blightfall is now **Recommended**. Rider remains a valid lower-friction **Alternative**.
- **Dungeons:** inherits the current San'layn Mythic+ direction as **Recommended**, with Rider retained as **Alternative**.
- **Delves:** San'layn + Blightfall is now **Recommended**. Rider remains an excellent mobility/lower-setup **Alternative**.
- **Open World:** Rider remains **Recommended**.

No third-party full talent import string is bundled. DK Mentor continues to show Hero Talent direction and source-backed visual markers without pretending a partial marker set is an exact guide import.

## San'layn / Blightfall guidance

The Unholy guide now includes a compact timing section for the current Blightfall profile:

- extend plague duration through the Dark Transformation window;
- align Soul Reaper when available;
- consume the disease setup with Blightfall near the end of the window;
- follow the payoff with Putrefy to restore diseases;
- keep the needed Lesser Ghoul setup available for Soul Reaper.

The existing Mythic+ Epidemic-at-3+-targets marker is preserved for the Rider alternative; 3.3.3 does not invent a new target-count threshold where the source guidance did not establish one.

## PvP remains review-pending

Unholy PvP ordering is intentionally unchanged. Icy Veins' current PvP guide still predates Blizzard's September 22 San'layn PvP buffs and retains the earlier Pet/Disease ambiguity. DK Mentor therefore keeps:

- **Pet / Rider:** provisional Recommended
- **Disease / San'layn:** Alternative
- freshness: **REVIEW PENDING**

## Blood, Frost, gear, and Valeera

- Blood PvE remains REVIEW PENDING because the current Wowhead talent guide still predates the September 22 tuning by one day.
- Frost PvE remains REVIEW PENDING because the current Wowhead talent guide still predates the September 22 tuning.
- Gear targets, trinkets, crafting, tier/Catalyst, stat priorities, runeforges, and consumables do not require target replacements from this audit.
- Valeera role, Curio, poison, Leveling, Hard Delve, and Nemesis/Azta'rec presets remain unchanged.
- No newer official Death Knight/Valeera hotfix after the reviewed September 23 changes requires a 3.3.3 runtime workaround.

## Scope boundary

3.3.3 does **not** change the combat engine, Assisted Combat integration, HUDs, Survival Coach, Talent Tree runtime, Gear Mentor, Valeera runtime, Preparation, Meta Pulse provider, or Loadout Pilot boundary. The built-in MetaData snapshot remains explicitly dated **2026-09-08** rather than being partially refreshed from mixed samples.
