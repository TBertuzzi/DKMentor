# DK Mentor 3.0.13 — Live Test Checklist

Install **3.0.13 Test** over **3.0.12** and verify:

## Gear Mentor readability
- Open **Código do DK → Mentor de equipamento**.
- Check **Visão geral** and confirm the **Direção de atributos** panel text is fully readable.
- Open **Melhorias** and confirm both columns are crisp and no longer faded behind the panel.
- Open **Berloques** and confirm the **Orientação rápida** rows are crisp.
- Open **Fontes** and confirm source labels look normal inside each source panel.
- Confirm the **Season 2 tier set** title/progress text is readable.

## Tooltip lifecycle regression
- Hover several gear cards.
- Move the cursor off the cards and outside the UI.
- Confirm the WoW tooltip disappears cleanly.

## General regression
- Switch between all Gear Mentor tabs.
- Change spec and reopen the Gear Mentor.
- Reload UI and confirm no Lua errors appear.
