# DK Mentor 3.0.16 — Live Test Checklist

Install **3.0.16 Test** over **3.0.15** and verify:

## Codex navigation
- Open **Código do DK / DK Codex**.
- Confirm Current / Blood / Frost / Unholy still show specialization icons.
- Confirm **Current** uses the currently active specialization icon.
- Confirm left-side menu labels fit without `...` in ptBR and enUS.
- Confirm the full section name still appears in the large content title.

## Gear Mentor — Crafting
- Open **Mentor de equipamento > Criação**.
- Confirm crafted recommendations are shown as item cards with icons.
- Hover every craft card and verify the native WoW item tooltip appears.
- Confirm the DK Mentor tooltip footer shows priority, slot, crafting source, embellishment and the recommendation reason.
- Move the mouse away and confirm the tooltip disappears normally.

## Gear Mentor — text wrapping
- Open **Berloques** and confirm all guidance sentences wrap fully without ending in `...`.
- Open **Melhorias** and confirm all Crest/upgrade guidance wraps fully without ending in `...`.
- Open **Equipamento** / **Visão geral** and confirm long item names can wrap instead of being manually shortened.
- Confirm tier bonus cards show the 2p/4p state cleanly; hover them for the full bonus explanation.

## Localization
- With language set to ptBR, verify UI explanations are Portuguese.
- Proper item names may follow the WoW client localization.
- Switch to enUS and confirm the same screens still fit.

## Regression
- Check Overview, Gear, Crafting, Sources, Trinkets and Upgrades.
- Check Combat and Settings tabs for obvious layout regressions.
