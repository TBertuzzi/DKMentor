# Project Artwork

This directory intentionally contains no final logo.

Before project submission, add an original square PNG at least 400 x 400 pixels. The artwork should be visually distinct from other addons and must not reuse the unmodified World of Warcraft logo, another project's avatar, or unlicensed art.

Suggested filename:

```text
assets/dk-mentor-logo-800.png
```

Project artwork is not included in the in-game addon release ZIP.
